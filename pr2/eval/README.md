# eval — набір для оцінювання якості детектора

## Структура

```
eval/
├── README.md           ← цей файл
├── expected.json       ← очікувані результати для кожного зображення
├── evaluate.py         ← скрипт для автоматичного порівняння
└── images/             ← тестові зображення (5–7 штук)
    ├── dogs.jpg
    ├── street.jpg
    ├── kitchen.jpg
    ├── office.jpg
    └── park.jpg
```

## Як використовувати

1. Покладіть тестові зображення в `eval/images/`.
2. Опишіть очікувані об'єкти у `expected.json`.
3. Запустіть `python eval/evaluate.py` — скрипт прогонить детектор і порівняє з очікуваним.

## Типи помилок

- **True Positive (TP):** правильно знайдений об'єкт
- **False Positive (FP):** хибне спрацювання (детектор «бачить» те, чого нема)
- **False Negative (FN):** пропуск (об'єкт є, але детектор його не знайшов)
- **Wrong class:** об'єкт знайдений, але з неправильним класом
- **Duplicate:** один і той самий об'єкт виявлений кілька разів
